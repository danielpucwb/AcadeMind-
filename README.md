# AcadeMind

Orientador acadêmico de pós-graduação — rodando localmente no Windows com GPU.

## Stack

- **Backend:** Python + FastAPI + SQLAlchemy (SQLite assíncrono)
- **Frontend:** HTML/CSS/JS (SPA, sem framework)
- **Transcrição:** faster-whisper (CUDA — RTX 4080)
- **Conversão Office→PDF:** LibreOffice headless
- **Concatenação PDF:** PyMuPDF (fitz)

## Execução

```bat
start.bat
```

Acesse: [http://localhost:8000](http://localhost:8000)
